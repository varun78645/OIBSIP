
# Basic Weather App

## About the Project
This project is a Basic Weather App developed using Python.

It fetches current weather information for a city entered by the user using the Open-Meteo API.

## Features
- Search weather by city name.
- Displays temperature in Celsius.
- Displays feels-like temperature.
- Shows weather conditions.
- Displays humidity.
- Displays wind speed.
- Handles invalid city names.
- Handles connection errors.

## Technology Used
- Python 3
- Requests Library
- Open-Meteo API
- Visual Studio Code

## How to Run
1. Install Python 3.
2. Install requests using:

pip install requests

3. Open the project folder in VS Code.
4. Run:

py main.py
